03 — Process

How I work with AI coding agents

  1. Spec first

    Scope, architecture and standards are written down before any code.

  2. One feature at a time

    Work is split into a feature list, with a contract for each step.

  3. Gates decide

    Lint, type check, tests, build and end-to-end must pass. A skipped check does not count as verified.

  4. Decisions recorded

    Each non-obvious choice goes into a decisions log, so the reasoning outlives the session.

  5. A human reviews

    Agent output is a draft until I have read it and accepted it.

The projects also test the framework. Building ai-invoice-intake turned up two bugs in it and nine improvement issues, all fixed upstream.
